Why does Phantom show a security notice on this page?

This collection is still on Solana's Devnet (a public test network) while we finish testing — it hasn't been announced yet. Wallets like Phantom are extra cautious about new, low-traffic pages and test networks in general, so an unfamiliar-site notice here is expected and not a sign that anything is wrong. It's the same reason your own wallet may ask you to double-check before connecting to any brand-new site.

Once we move to Solana mainnet for the real launch, this page will have real transaction history and community visibility, which is what these warnings look for — so it should not appear anymore. If it ever does, please always read the details in the popup before approving.
